# Intelligent Agents evidence storage

This folder will store supporting files that are appropriate for public release.

Recommended subfolders will be created as evidence becomes available:

- `discussions/`
- `team-exercises/`
- `code/`
- `meeting-notes/`
- `feedback/`
- `supporting-documents/`

Use descriptive names such as `unit-01-agent-based-systems-initial-post.md` or `team-meeting-2026-08-12.md`. Do not upload confidential information, private correspondence, personal contact details or material that the team has not agreed may be published.
