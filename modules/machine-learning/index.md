## Activity 01 — Unit 3: Correlation and regression

Four executed Python notebooks explore covariance and Pearson correlation, simple linear regression, multiple linear regression and polynomial regression. Controlled changes test sensitivity to noise, influential observations, predictor selection and polynomial degree.
