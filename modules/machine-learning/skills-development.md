# Machine Learning — Skills and development

[Module overview]({{ '/modules/machine-learning/' | relative_url }})

## Baseline evidence from Activity 01

The table records techniques demonstrated in the activity artefacts. It does not infer an independent proficiency score from AI-assisted work.

| Skill area | Evidence in ML-01 | Development action | Completion evidence to retain |
|---|---|---|---|
| Python debugging and reproducibility | Corrected SciPy reference, fixed seeds, executed cells and environment record | Rerun the notebooks and independently explain one change in each | Saved rerun outputs and concise explanations |
| Statistical interpretation | Covariance versus r; nonlinearity; influential observation | Repeat noise comparisons with a second seed | Paired result tables with discussion of variation |
| Regression evaluation | Coefficients, R² and held-out RMSE | Add residual plots and repeated validation on a larger suitable dataset | Diagnostic plots and validation summary |
| Model complexity and data coverage | Polynomial degree and extrapolation experiments | Compare interpolation and time-aware forecasting designs | Explicit evaluation design and error analysis |
| Professional practice | Attribution, units, source limitations and responsible handling of outliers | Document source, intended use, permissions and limitations for future datasets | Dataset documentation attached to each new artefact |

## Priority

Before expanding to more complex algorithms, establish a repeatable workflow for checking data provenance, selecting evaluation data, interpreting errors and reporting uncertainty. Revisit this table when the next activity adds evidence.
